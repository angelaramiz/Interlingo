# Decisión 1 — Concepto del producto

**Fecha:** 2026-08-12

## Decisión
LengLearning = plataforma de **aprendizaje de idiomas basada en temas de interés**. Aprender un idioma mientras aprendes algo útil.

## Detalles
- El **tema es el vehículo**; el **idioma es la habilidad principal** que se entrena.
- **Dos rutas de progreso simultáneas**: ruta de idioma y ruta de tema.
- **Motor adaptativo** que evalúa ambas: si falla el idioma → baja dificultad lingüística; si falla el concepto → simplifica la explicación técnica.
- **Secuencia de actividades**: comprensión lectora → producción guiada → respuestas escritas → explicación propia del tema en el idioma objetivo.
- **Métrica principal**: cuánto entiende y expresa el usuario en el idioma mientras estudia el tema.

## MVP acordado
Ciclo: **meta → diagnóstico → lección → evaluación → ajuste**.
- Usuario indica tema, idioma y objetivo.
- IA genera plan adaptativo de 5 niveles.
- Cada nivel: texto breve en el idioma objetivo, vocabulario clave, preguntas de comprensión, evaluación y ajuste según desempeño.

## Diferencial
No estudias inglés con frases genéricas; aprendes inglés leyendo, respondiendo y creando contenido sobre temas que realmente te interesan.
