# Skills del Proyecto — LengLearning

Skills planificadas (cada una con su `SKILL.md` en `.agents/skill/<nombre>/`):

1. **prompt-engine** — Plantillas del motor de prompts: interpretar meta, diagnóstico, plan, lección, evaluación, corrección, ajuste de nivel. Define el JSON de salida.
2. **evaluacion-adaptativa** — Reglas de calificación: opción múltiple, ordenar palabras, rúbrica para respuestas escritas (comprensión, vocabulario, claridad, uso técnico).
3. **modelo-datos** — Esquema SQLite y traza de aprendizaje (usuario, meta, tema, niveles, evaluaciones, errores repetidos).

Documento base `SKILL.md` en la raíz: arquitectura `.agents/` (sistema de memoria y contexto).
